# Pharma Intelligence AI — Dashboard UX Update

## Design direction

The dashboard uses the **Espresso & Bronze** palette for a premium, restrained commercial-intelligence interface.

- Espresso: primary dark surfaces
- Bronze: subtle accent color
- Neutral supporting tones for readability
- No white or blue backgrounds
- Avoid gradients, neon accents, and overly decorative styling

## Installation

1. Back up the current `dashboard.py`.
2. Replace it with the updated dashboard file.
3. From the `Pharma_Intelligence_AI` project directory, run:

   ```powershell
   python -m py_compile dashboard.py
   python -m streamlit run dashboard.py
